This site is deliberately plain.

One font: whatever your device already has. One font size, for everything: headings, navigation, dates and body text. Hierarchy comes from bold weight, spacing and position, not from size. Four shades of grey and no accent colour.

The reason is that the information here should be easy to find and easy to read, and nothing should compete with it. Pages that change over time, Reading and Routine, show the date they were last updated, so you can tell how current they are.

The site is three pages and this list of posts. It is built with Astro from Markdown files in a public GitHub repository and published by GitHub Actions to GitHub Pages. A post is one Markdown file.
